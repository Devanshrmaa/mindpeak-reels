## 4. Bing-Only Indexing Assessment

Commit `69b7466` (2026-06-14) added `src/lib/bingIndexing.ts` and `proxy.ts` changes that serve:
- Bingbot → `X-Robots-Tag: index, follow`
- Googlebot and all others → `X-Robots-Tag: noindex, follow`

…for thin pages (individual practice/PYQ question pages + non-curated city doorway pages that serve 200 OK).

**Assessment: Technically sound.** This is per-bot robots header differentiation (not content cloaking). Serving different `X-Robots-Tag` values to different crawlers is permitted under Google's guidelines as long as the HTML content is identical — which it is here (ISR cache is bot-agnostic; only the header changes). The Bing sitemap is not linked from `robots.txt`, so Googlebot has no discovery pathway.

**Risk to monitor:** If Google ever disputes this as cloaking (unlikely given identical HTML), the exposure would be the thin practice/question pages — not the main recovery effort. Low risk.
