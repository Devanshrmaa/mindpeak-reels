## Architecture Overview

MindPeak uses a layered metadata system:

| Layer | Pattern | Pages Covered |
|---|---|---|
| `app/layout.tsx` | Global fallback defaults | All pages |
| `buildSEOLandingMetadata(slug)` | Pulls from `seoPageData.ts`, generates full OG | ~40 SEO landing pages |
| Static `metadata` export | Manually written per page | ~18 pages |
| `generateMetadata()` dynamic | Blog posts, catch-all route | 500+ dynamic pages |
| `resolveSlugMetadata()` | Master resolver for all catch-all dynamic pages | 490+ pages |

**Strengths:**
- ✓ All 500+ dynamic (catch-all) pages have OG tags and Twitter cards via `resolveSlugMetadata`
- ✓ Category-based OG image resolver (`ogImage.ts`) assigns correct images per page type
- ✓ Blog posts use hand-tuned CTR overrides (`blogSeoOverrides.ts`) for 10 top impression posts
- ✓ All pages include `en-IN` + `x-default` hreflang alternates
- ✓ Structured data (JSON-LD) on key pages: EducationalOrganization, Course, HowTo, FAQPage, NewsArticle, Person
- ✓ No root-level canonical (prevents homepage canonicalization of all pages)
- ✓ Geo meta tags on location pages
- ✓ `metadataBase` set to `https://mindpeakinstitute.com` (relative OG images work)

**Critical Gaps:**
- ❌ 9 high-traffic tool/hub pages have no OG or Twitter tags — show blank previews on WhatsApp/social
- ⚠️ 4 page.tsx files have descriptions > 155 chars (will be truncated by Google mid-sentence)
- ⚠️ Root layout default description is 159 chars (fallback for any page with no custom desc)
- ⚠️ 3 entries in `seoPageData.ts` have descriptions > 155 chars that get `.slice(0, 155)` mid-word
- ⚠️ Contact page title has brand name "MindPeak" appearing twice
