## 4. Remaining Recommendations (Not Implemented — Future Work)

1. **Contact page BreadcrumbList JSON-LD** — Visual breadcrumb exists but no JSON-LD. Add `BreadcrumbList` to `app/contact/page.tsx` metadata `other`.

2. **Free-trial page** — Consider adding `Event` or `Service` schema to highlight the free demo class offering.

3. **Contact page duplicate EducationalOrganization** — The root layout already emits `EducationalOrganization`. The Contact view emits it again. Replace the Contact view's `EducationalOrganization` with an `@id` reference to the root entity.

4. **SearchAction scope** — Currently targets `/blog?q=`. Consider broadening to a dedicated search page or the homepage.

5. **AggregateRating on root EducationalOrganization** — City pages include AggregateRating per-city. Adding a site-wide aggregate rating to the root layout organization would enable star ratings in Google Search.

6. **Course pages (`/course/[slug]`)** — Individual course detail pages. Check if `CourseDetail` view emits Course schema.
